
# Modèle économique

## 📐 Fondements théoriques

### 1. Distinction Nuqud / Fulus

| Caractéristique | Nuqud (نقود) | Fulus (فلس) |
|-----------------|--------------|-------------|
| Rôle | Mesure + Réserve de valeur | Moyen d'échange UNIQUEMENT |
| Riba | STRICT (ni surplus, ni délai) | ASSOUPLI (surplus ≤5%) |
| Exemples | Or, argent, sel, blé | Monnaie convertible |
| Thermodynamique | ~0% taux d'intérêt réel | Vélocité comme SEULE fonction |

**Règle d'or :** Dès qu'une commodité entre dans le panier Grondona, elle devient *nuqud*.

### 2. Paramètre de bifurcation Λ
Λ = (D · r) / Ė_low

- **D** = Dette totale
- **r** = Taux d'intérêt moyen
- **Ė_low** = Taux d'extraction d'énergie/matières premières

**Seuil critique :** Λ > 1 → effondrement inévitable

### 3. Équation de circulation
M_f · V(t) = T(t)

- **M_f** = Masse monétaire (fulus)
- **V(t)** = Vélocité dynamique (pilotée par l'IA)
- **T(t)** = Transactions réelles (issues du souq)

### 4. Fonction d'optimisation
U = αN + βV - γE - δC

- **N** = Négentropie (organisation)
- **V** = Vélocité de circulation
- **E** = Entropie (désordre)
- **C** = Concentration de richesse (Gini)

## 🔬 Preuve de stabilité (Lyapunov)

### Fonction de Lyapunov
ℒ(X) = (X - X*)ᵀ P (X - X*)

### Condition de stabilité
(A - BK)ᵀ P + P(A - BK) = -Q

Avec **Q ≻ 0**, le système est globalement asymptotiquement stable.

### Extension stochastique
dX_t = F(X_t) dt + Σ dW_t

Avec **𝒜ℒ < 0**, le système est stable en probabilité.

## 📊 Indicateurs clés

### ESG (Environmental, Social, Governance)

| Composante | Indicateurs |
|------------|-------------|
| Environmental | Entropie logistique, émissions carbone, part des renouvelables |
| Social | Chômage, coefficient de Gini, Zakat distribuée |
| Governance | Transparence, conformité hisba, auditabilité blockchain |

### Stabilité monétaire

- **Λ** : Paramètre de bifurcation (Λ < 0.7 = stable)
- **Vélocité** : Tours par an (cible ≥ 10)
- **Réserves nuqud** : En grammes d'or équivalent

### Logistique

- **Entropie** : Perte par dégradation/retard
- **Délai** : Jours de livraison moyen
- **Capacité** : Tonnes disponibles

## 🔄 Dynamique du système

### Agents

1. **Guildes** : Produisent, stockent, vendent en gros
2. **Commerçants** : Achètent, revendent en détail
3. **Consommateurs** : Achètent pour usage
4. **Muhtassib** : Inspecte, certifie

### Marché (Souq)

- Appariement offre/demande main à main
- Inspection du muhtassib
- Intervention du CRD (prix plancher/plafond)
- Logistique (délais, coûts de transport)

### Zakat

- 2.5% sur l'épargne en nuqud
- 10% sur les récoltes irriguées
- 5% sur les récoltes pluviales
- 2.5% sur le bétail
- **Payable UNIQUEMENT en nuqud**

### 8 catégories de bénéficiaires

1. Fuqara (pauvres)
2. Masakin (nécessiteux)
3. Amilin (collecteurs)
4. Muallafati (nouveaux musulmans)
5. Riqaab (affranchissement)
6. Gharimin (endettés)
7. Fi Sabilillah (cause d'Allah)
8. Ibn Al-Sabil (voyageurs)
