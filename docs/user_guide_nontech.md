# Guide utilisateur – Non-techniciens

## À qui s'adresse ce guide ?

Ce guide est destiné aux **non-techniciens** : commerçants, responsables de guildes, muhtassib, élus municipaux.

## Pourquoi ce système ?

- **Pas d'intérêt (riba)** – l'argent ne s'auto-engendre pas
- **Ancrage réel** – l'or et l'argent garantissent la valeur
- **Gouvernance humaine** – le muhtassib contrôle le marché
- **Zakat politique** – collectée par l'émir, redistribuée

## Utilisation quotidienne

### Commerçant

1. **Vendre** : proposez vos produits sur le marché (souq)
2. **Recevoir** : les paiements se font en **fulus**
3. **Certification halal** : faites certifier vos produits
4. **Zakat** : 2.5% sur votre épargne en nuqud

### Consommateur

1. **Acheter** : utilisez vos fulus pour acheter des biens
2. **Confiance** : le muhtassib garantit les poids et la qualité halal
3. **Épargner** : convertissez vos fulus en nuqud

### Muhtassib (inspecteur)

1. Vérifier les balances et les mesures
2. Contrôler les certificats halal
3. Signaler les fraudes
4. L'IA vous assiste, mais c'est vous qui décidez

## Transférer entre zones (BRI)

1. Allez dans l'interface de transfert
2. Choisissez la zone source et la zone cible
3. Entrez le montant en grammes d'or (nuqud)
4. Validez – les frais sont déduits automatiquement

## Que faire en cas de crise ?

- Le **CRD** libère des stocks de première nécessité
- La **Zakat** est redistribuée en urgence
- Le **muhtassib** renforce les inspections
- Les **guildes** mutualisent leurs ressources

## Glossaire

| Terme | Définition |
|-------|-------------|
| Nuqud | Or et argent, réserve de valeur, pas d'intérêt |
| Fulus | Monnaie locale qui circule vite |
| CRD | Stock régulateur pour stabiliser les prix |
| Muhtassib | Inspecteur du marché |
| Hisba | Fonction d'inspection |
| Zakat | Impôt purificateur (2.5% sur nuqud) |
| Bayt al-mal | Trésorerie publique islamique |
| BRI | Belt and Road Initiative |
